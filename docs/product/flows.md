# Core User Flows

## Start / authentication
User signs in through WorkOS, lands in Mail, and sees the unified inbox when accounts are connected.

## Connect account
Settings → Accounts → connect/authorize mailbox → validate connection → discover folders → sync initial mailbox state → show account health/status.

## Daily triage
Unified Inbox → open thread → read/reply/archive/snooze/move/star → move through messages with keyboard or pointer → use bulk actions when needed.

## Compose
Compose → select sending identity → recipients → subject → Rich Text / Markdown / Plain Text → attachments/signature → send now or schedule → recover safely on failure.

## Reply
Open conversation → Reply / Reply all / Forward → default to identity/account that received the message → autosave draft → send.

## Search
Focus global search → free text or operators/filters → inspect result list → open result while retaining search context.

## Snooze
Choose preset/custom time → message leaves active inbox → returns at selected time without changing its original received timestamp.

## Scheduled send
Compose → Schedule send → explicit date/time/timezone → message appears in Scheduled → user can edit, reschedule, send now, or cancel back to Draft.

## Rules
Rules → create condition(s) → choose all/any → add action(s) → validate → save/enable → deterministic execution.

## Contacts
Contacts → browse/search/edit → compose directly or use autocomplete from composer.

## Settings
Manage accounts, identities, signatures, composer defaults, inbox behavior, appearance, notifications, keyboard preferences, and security.
