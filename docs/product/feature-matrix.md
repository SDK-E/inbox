# Feature Matrix

| Area         | Required                                                                               |
| ------------ | -------------------------------------------------------------------------------------- |
| Auth         | WorkOS AuthKit, protected routes, org membership, roles                                |
| Accounts     | Multiple mailboxes, connect/reconnect/disconnect, health                               |
| Folders      | Real nested IMAP folders                                                               |
| Inbox        | Unified + per-account/folder                                                           |
| Reader       | Threads + individual mode, safe HTML/plain text, attachments                           |
| Actions      | Read, unread, star, archive, move, trash, restore, delete                              |
| Composer     | Rich Text, Markdown, Plain Text, CC/BCC, identities, signatures                        |
| Drafts       | Autosave, resume, failure-safe                                                         |
| Sending      | Send now, scheduled send, retry/idempotency                                            |
| Search       | Text + operators + advanced filters                                                    |
| Contacts     | Address book, org users, recent recipients                                             |
| Snooze       | Presets/custom time, resurfacing                                                       |
| Rules        | Multiple conditions/actions, deterministic execution                                   |
| Productivity | Bulk actions, keyboard, command palette, context menus, DnD                            |
| Settings     | Accounts, identities, signatures, inbox, composer, appearance, notifications, security |
| Admin        | Users, roles, mailbox access, audit                                                    |
| UX           | Three-pane desktop, responsive tablet/mobile, light/dark/system                        |
| Quality      | WCAG 2.2 AA, Vitest, Playwright, security, performance, resilience                     |
