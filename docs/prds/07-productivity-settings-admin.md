# PRD — Productivity, Settings & Admin

## Productivity

- Bulk selection/range selection.
- Bulk archive/move/read/star/snooze/delete.
- Keyboard shortcuts.
- Command palette.
- Context menus.
- Drag-to-folder with non-drag alternative.
- Undo for reversible actions.

## Settings

Accounts, identities, signatures, composer defaults, conversation mode, density, pane widths, notifications, appearance, keyboard preferences, security.

## Admin

Employee/user administration, roles, mailbox access, permissions, audit visibility where required.

## Acceptance

Core workflows are keyboard-operable; preferences persist per user; admin authorization is server-enforced; sensitive operations are auditable.
