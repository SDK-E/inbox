# SDK / Inbox Branding

## Identity

Inbox uses SDK Enterprises' engineering-led visual language: technical, precise, calm, credible, compact, and understated.

Canonical SDK colors:

```css
--sdk-green-950: #082003;
--sdk-green-500: #2cdb16;
--sdk-green-100: #d7e8d3;
```

Primary brand typeface: **JetBrains Mono**.

Inbox wordmark: `Inbox.` where the dot is a circular `#2cdb16` accent. Use the existing light/dark logo assets; do not redraw or arbitrarily recolor them.

## UI direction

Prefer:

- compact controls;
- restrained borders;
- flat/subtle surfaces;
- strong alignment;
- clear hierarchy;
- green accents used intentionally;
- consistent 4/6/8px-ish restrained radii;
- Lucide as the default icon family.

Avoid:

- glassmorphism;
- excessive gradients/blur/glow;
- giant rounded cards;
- heavy shadows;
- decorative animation;
- generic SaaS dashboard styling.

Dark mode must be designed, not inverted. Brand choices never override WCAG 2.2 AA contrast/focus requirements.

## Copy

UI copy is direct, concise, specific, and human. Avoid marketing filler, generic AI phrasing, rhetorical symmetry, and unnecessary explanation.
